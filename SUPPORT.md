# Support

Start with the [documentation site](https://nix-forge.github.io/nix-homelab/),
especially [setup](docs/setup.md), [testing](docs/testing.md), and the
operations guide. The host remains responsible for storage, credentials,
backups, and provider accounts.

For a bug or a reproducible module problem, [open an issue](https://github.com/nix-forge/nix-homelab/issues/new).
Include the commit or input revision, NixOS version, enabled profile or
service, relevant options, the command that failed, and the smallest useful log
excerpt. Remove credentials, VPN profiles, private host details, and personal
paths before posting.

Use [SECURITY.md](SECURITY.md) for suspected vulnerabilities. Do not disclose
security-sensitive details in a public issue.

This project does not provide managed homelab deployments or support for a
private media library. Public, minimal reproductions are the best way to get
help.
