# Publication rules

Publish portable setup instructions, cited research and summarized verification.
Use repository-relative links and documentation addresses. Keep personal paths,
disk identifiers, private network names, raw logs and provider profiles out of
tracked documentation. User-provided secrets belong in the consuming nix-seal
catalog, never in this flake.

Review links and attribution before publishing. Do not claim platform runtime
coverage, successful restores, benchmarks or independent security audits without
recorded evidence. A scheduled CI job is not evidence that it has passed.
